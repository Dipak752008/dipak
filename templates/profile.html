PROJECT FEATURES

What I Built

🔐

Authentication

Student registration and login system with password hashing and session management.

👨‍💼

Admin Role

Role-based access where the admin can add, edit and delete student records.

👨‍🎓

Student Records

Student name, roll number, attendance, marks, branch and profile photo management.

🔎

Search & Filter

Search students by name and filter records using attendance percentage.

📑

Pagination

Student records are divided into pages for better performance and usability.

📸

Photo Upload

Students can have profile photos stored inside the uploads folder.

📢

Notice Board

Important college announcements such as exams, holidays and project submissions.

🤖

AI Study Tips

Students enter marks and subject information to receive personalized AI study suggestions.

💡

AI Doubt Assistant

An AI-powered feature that helps students get answers to their study-related doubts.

🌙

Dark Mode

Modern theme switching using Bootstrap theme support and localStorage.

🏫

Branch Management

Separate student counts for Computer, Mechanical, Civil, Electrical, ENTC and AI-DS.

📱

Responsive Design

The portal is designed to work across desktop, tablet and mobile screens.
